Automação com Python

Script em Python para automatizar o processamento de dados de produtos a partir de um arquivo CSV.

🎯 Objetivo

Praticar automação de tarefas repetitivas com Python, trabalhando leitura, tratamento e manipulação de dados tabulares.

🛠️ Tecnologias utilizadas

- Python;
- Manipulação de arquivos CSV.

📁 Estrutura

- `codigo.py` — script principal da automação
- `auxiliar.py` — funções auxiliares
- `produtos.csv` — base de dados utilizada como exemplo

📌 Status

Projeto de estudo — prática de automação e manipulação de dados em Python.
